# College Exam Paper Generator

A lightweight web tool for preparing high-resolution college exam question papers. Matches Photoshop pre-press layouts (2-Up Duplicate Half-Cut and Full A4 Single Page) with dynamic pagination.

## Features
- **2-Up Duplicate (Half-Cut)**: A4 Landscape (3508 x 2480 px @ 300 DPI)
- **Full A4 Size**: A4 Portrait (2480 x 3508 px @ 300 DPI)
- **Dynamic Flow**: Automatically eliminates gaps after Q10; fits short papers into 1 page cleanly.
- **Manual Entry Form**: Paper code, 10-box hall ticket, college details, Section A (Q1-8), Section B (Q9-13).
- **Supports**: Commerce accounts tables, KaTeX Math formulas, and Telugu Unicode text.
- **Export**: 300 DPI JPG export and Zero-Margin Print to PDF.

## How to Run
Simply open index.html in any browser.
